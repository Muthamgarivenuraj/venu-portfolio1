Agency Landing Page

Modern responsive landing page for a digital agency, focused on speed and clear service messaging.

Problem

The client needed a clean, mobile-first landing page that loads fast on 4G and highlights services & primary CTA clearly.

Solution

  • Semantic HTML + utility-first CSS structure
  • Compressed images to PNG and enabled loading="lazy"
  • SEO meta + Open Graph preview for social sharing
  • Formspree contact form (GitHub Pages friendly)
  • Deployed to Netlify/GitHub Pages for quick delivery

Result

90+ Lighthouse score, LCP ~2.5s on mobile, and a working lead form. Layout scales smoothly from 360px to desktop.

Tech Stack

HTML • CSS • JavaScript • Formspree • Netlify/GitHub Pages
