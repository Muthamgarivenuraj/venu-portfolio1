Portfolio Template

Responsive personal portfolio template with theme switcher, clean sections, and fast loading.

Problem

Creators needed a simple, customizable portfolio to showcase work quickly without a backend.

Solution

  • Semantic HTML with modular sections (Hero, About, Services, Projects, Contact)
  • Theme switcher (light/dark) using CSS variables + small JS
  • Optimized images (PNG with loading="lazy") and basic SEO/OG tags
  • Contact form via Formspree (static-friendly)
  • Deployed on GitHub Pages / Netlify

Result

Loads fast on mobile, scores 90+ on Lighthouse (Perf/SEO), and is easy to adapt to any personal brand.

Tech Stack

HTML • CSS • JavaScript • Formspree • GitHub Pages/Netlify
